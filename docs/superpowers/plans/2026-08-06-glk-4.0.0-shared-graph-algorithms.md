# GLK 4.0.0 Shared Graph Algorithms Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove duplicate maximum-cardinality selection and cycle-detection algorithms from `graph_model.py` so formal and compatibility graph paths consume the canonical kernel algorithms.

**Architecture:** Add two deterministic pure functions to `graph_kernel.py`: one resource-aware maximum-compatible selector and one acyclicity assertion. Route formal topology projection and the legacy in-memory compatibility model through those functions, then delete the private duplicate searches. Preserve all public GO, causal, CELL, receipt, state, error-message, and resource-capacity behavior.

**Tech Stack:** Python 3.12+ standard library, pytest, AST structural tests, existing GLK validators.
