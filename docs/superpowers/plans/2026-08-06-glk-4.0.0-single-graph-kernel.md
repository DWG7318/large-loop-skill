# GLK 4.0.0 Single Graph Kernel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Establish one canonical, side-effect-free GLK graph topology and maximal-safe activation kernel while preserving every accepted GLK 3.1 artifact and public validation behavior.

**Architecture:** Extract the current formal topology and activation algorithms from `run_state.py` into `graph_kernel.py`, make `run_state.py` a compatibility consumer for this slice, and make `run_validation.py` import graph facts directly from the kernel. New AST-based structure tests prohibit reintroducing a second current implementation. Causal recovery, shared Loop controls, schemas, versions, migration, packaging, and remote state remain unchanged.

**Tech Stack:** Python 3.12+ standard library, frozen dataclasses, pytest, jsonschema, YAML, existing GLK repository validator.

---

## Slice Boundary

**Objective:** Move graph topology recomputation and maximum-cardinality maximal-safe activation to one canonical module.

**Done means:**

- `graph_kernel.py` is the sole top-level definition site for the extracted graph types and functions;
- `run_state.py` re-exports those exact objects and contains no duplicate extracted algorithm;
- `run_validation.py` imports graph topology and activation directly from `graph_kernel`;
- accepted 3.1 graph, closure, admission, validation, schema, and repository tests pass;
- no version, schema, template, shared-control, migration, release, tag, or remote change occurs.

**Non-goals:** causal recovery migration from `graph_model.py`, shared Loop control extraction, validator-layer decomposition, version 4.0 identity publication, or file deletion outside the exact duplicated topology blocks.

**Owner boundary:** all work in this slice is local category A. No account, key, external service, release authorization, or production input is required.

CANONICAL_GRAPH_DEFINITIONS = {
    "GraphConstraint",
    "GraphNode",
    "GraphEdge",
    "FrozenGraphTopology",
    "GraphStateProjection",
    "graph_topology_payload",
    "recompute_graph_topology",
    "_maximum_compatible_go_ids",

}


def test_extracted_graph_definitions_have_one_current_owner():
    owners = {name: [] for name in CANONICAL_GRAPH_DEFINITIONS}
    for path in sorted(SCRIPTS.glob("*.py")):
        tree = ast.parse(path.read_text(encoding="utf-8"))
        for node in tree.body:
            if isinstance(node, (ast.ClassDef, ast.FunctionDef)) and node.name in owners:
                owners[node.name].append(path.name)
    assert owners == {
        name: ["graph_kernel.py"] for name in CANONICAL_GRAPH_DEFINITIONS
    }


def test_first_slice_size_budget_prevents_duplicate_growth():
    kernel_lines = len((SCRIPTS / "graph_kernel.py").read_text(encoding="utf-8").splitlines())
    state_lines = len((SCRIPTS / "run_state.py").read_text(encoding="utf-8").splitlines())
    validator_lines = len((SCRIPTS / "run_validation.py").read_text(encoding="utf-8").splitlines())
    assert kernel_lines <= 420
    assert state_lines <= 760
    assert kernel_lines + state_lines <= 1_030
    assert validator_lines <= 2_148


def test_repository_distribution_requires_graph_kernel():
    validator_source = (SCRIPTS / "validate_glk.py").read_text(encoding="utf-8")
    repository_test_source = (
        ROOT / "tests" / "test_repository_310.py"
    ).read_text(encoding="utf-8")
