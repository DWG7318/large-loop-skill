# GLK 2.3.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish GLK 2.3.1 as the six-role, Run-scoped GO DAG method with no READY state and mandatory maximal-safe multi-GO activation.

**Architecture:** Replace the obsolete GLK 2.0.0/2.3.0 control model with one Run-scoped Supervisor that owns a frozen GO DAG and maintains `WAITING_GO` and `ACTIVE_GO` sets. Keep graph state separate from the implementation/checking/verification phase, bind D0-D3 receipts to immutable candidate identities, and validate all templates and repository invariants in CI.

**Tech Stack:** Markdown specification, YAML templates, JSON Schema Draft 2020-12, Python 3.12+, pytest, PyYAML, jsonschema, GitHub Actions.
