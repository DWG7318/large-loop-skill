# GLK 2.4.0 Causal Recovery Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add evidence-bound causal tracing, minimal descendant invalidation, and maximal-safe GO reactivation to GLK without changing its six-role or WAITING/ACTIVE topology.

**Architecture:** Extend D2 dependency edges with explicit producer-to-consumer bindings. Represent one confirmed incident as an immutable causal trace, derive a minimal forward impact projection from changed refs, and re-project only affected GOs into the existing WAITING_GO/ACTIVE_GO scheduler while preserving historical receipts.

**Tech Stack:** Python 3.12+, dataclasses, pytest, YAML, JSON Schema Draft 2020-12.
