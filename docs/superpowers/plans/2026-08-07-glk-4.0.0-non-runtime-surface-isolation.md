# GLK 4.0.0 Non-Runtime Surface Isolation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove compatibility/reference engines and release/bootstrap tooling from the current GLK runtime script surface, leaving fewer than 8,000 production Python lines without changing accepted behavior.

**Architecture:** Keep `glk/scripts/` for current method validation, graph-kernel code, and native capacity calculation until the shared LCCoding control contract exists. Move the obsolete mutable graph model under `tests/support/`; move repository validation, packaging, and draft-bootstrap implementations under root `tools/`, retaining a thin compatible repository-validator entrypoint. Update only import/command paths, repository identity lists, and tests.

**Tech Stack:** Python 3.14, pytest, Git hash manifest, ZIP release validation.
