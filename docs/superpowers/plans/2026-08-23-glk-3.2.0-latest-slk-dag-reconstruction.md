> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Do not use subagents unless the Owner separately authorizes them. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the active GLK 3.1 kernel with a compact 3.2.0 Skill collection that owns only DAG orchestration while every GO reuses one Run-bound latest SLK baseline.

**Architecture:** Publish one main Skill plus three GLK-native child Skills. The Supervisor owns a multi-start `ALL`-join DAG, the roster, routing, Fusion, final D2, and the conditional D2 Repair GO; GO-local planning, models, Checker/Worker behavior, D0, D1, rework, communication, and work records remain SLK responsibilities. The release removes the old active runtime/kernel surface instead of maintaining a second compatibility implementation.

**Tech Stack:** Markdown Agent Skills, Python 3 repository validation, JSON SHA-256 manifest, pytest, GitHub Actions on Windows and Ubuntu.
