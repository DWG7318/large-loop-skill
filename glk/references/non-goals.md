# Non-goals

GLK does not define product intent, Proposal, Initialization, Calabash, Workflow,
UI, Simulation, Feature Slice, Delivery, centralized project security closure,
Chains, Stages, Barriers, Code Graphs, business graphs, module graphs, or
organizational structures.

GLK consumes a frozen Run contract and returns bounded evidence plus acceptance and
security handoff artifacts. It must not absorb upstream product-definition or
downstream project-release authority to bypass a blocker.
